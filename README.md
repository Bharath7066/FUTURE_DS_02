# customer_churn.pbix

This Power BI project focuses on Customer Churn Analysis to identify customer behavior, retention patterns, and factors affecting churn. The dashboard provides interactive visualizations such as churn rate, customer demographics, subscription details, monthly charges, and contract analysis. Various KPIs and charts were used to analyze trends and highlight customers likely to discontinue services. Data cleaning and transformation were performed using Power Query to ensure accurate reporting. The project helps businesses understand customer satisfaction and improve retention strategies through data-driven insights. This dashboard was created using Power BI with interactive filters, slicers, and visual analytics for better decision-making and business performance evaluation.
